# MG5
## Devlog
1. I think NavMesh is better when characters need to find their way to a place. For example, I know in League of Legends, I click somewhere and the character walks there. But for a game like Human: Fall Flat, I think physics is better because the characters need to jump, fall and interact with objects.

2. The for loop checks every bird in the array. Vector3.Distance checks how far each bird is from the player. If the bird is close enough, it will run away. So all the birds in the array can run away, but only the ones close to the player will actually run away.
